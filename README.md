# Pharos Network Community

Welcome to the Pharos Network community!

This is the starting point for becoming a contributor - improving code and docs, giving talks, etc.

## Introduction

Visit the [website](https://pharosnetwork.xyz/) for more information.

## Purpose

- **Bug Reports**: Encounter an error on the Pharos testnet? Let us know so we can investigate and fix it.
- **Feature Requests**: Have ideas to improve the Pharos ecosystem? Propose suggestions here and start discussions.
- **Documentation & Guides**: Need clearer instructions or updated documents? Submit requests for better documentation.

## How

- **Check Existing Issues**: Before creating a new issue, search existing issues to see if your error or request has already been reported.
- **Open an Issue**:
  - For bug reports, use the **Bug Report** template to create a new issue.
  - For feature requests, use the **Feature Request** template.
- **Follow Up**: After submitting an issue, our team and community will review it. We may request more information or clarification, so please monitor updates.

## Community Guidelines

- **Respect Others**: Treat everyone with politeness and kindness.
- **Stay On Topic**: Keep discussions focused on issues and requests.
- **Be Patient**: Our team works to address feedback promptly, but response times may vary.
